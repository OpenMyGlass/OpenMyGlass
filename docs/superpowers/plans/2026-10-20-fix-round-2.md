## Global Constraints

### Task 1: Glass cards and wake — #47, #48, #51, #52
- #47: Glass removes a dismissed card only when the phone's `NotificationRemoved` arrives. If no removal arrives within 5 s, the card is restored. Test in `NotificationStateTest`.
- #48: the icon view gets an explicit placeholder (or is hidden) when there is no icon. Covered by a binder check where testable, otherwise layout only.
- #51: `maxLines` on the notification text.
- #52: separate wake locks for navigation and notifications.

### Task 2: Dictation — #54, #58, #59
- #59: the phone's expiry restarts when the transcript is sent. Test in `DictationServiceTest`.
- #54: a 20 s deadline in TRANSCRIBING/SENDING shows "Phone not reachable".
- #58: Back during SENDING waits for the result (it is shown, then the screen closes).

### Task 3: Media sync and link status — #64, #66, #44, #43
- #64: LISTING/WAITING_SERVER time out after 30 s back to IDLE, with a status message. Test.
- #66: after a run with failures, or with new media announced during it, one follow-up run in 5 min if the conditions still hold. Test with an injected delay.
- #44: `LinkManager.start()` resets the backoff. Test.
- #43: the service recomputes the notification on Bluetooth state changes; the text combines "bridge off" with a connected companion. `ServiceStatus` test.

### Task 4: Maps card flicker, APK size, docs — #35, #57, #50, #73, #37, #30

- #57: `abiFilters` arm64-v8a + armeabi-v7a, plus x86_64 for emulator testing. Record the APK size.
- Docs:

  - #73: delete-after-sync applies only to files saved while it is on;
  - #37: delete capture files after use (debug screen text plus docs);
  - #30: KDoc for `IOException` on `CompanionLink`/`ConnectionManager` calls.
